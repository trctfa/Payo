# 沒有電腦：只用手機安裝

可以。你只要用紅米的瀏覽器下載安裝檔（APK），再允許安裝即可。

---

## 第 1 步：用手機打開下載頁

1. 用手機 Chrome / 瀏覽器打開下面其中一個連結：

**直接下載（建議先試這個）：**  
https://github.com/trctfa/Payo/raw/cursor/ime-notification-switcher-5dcd/ime-switcher/release/ime-switcher.apk

**或先打開資料夾再點檔案：**  
https://github.com/trctfa/Payo/tree/cursor/ime-notification-switcher-5dcd/ime-switcher/release

2. 若 GitHub 要登入，先登入你的 GitHub 帳號  
3. 點 `ime-switcher.apk` → **Download / 下載**

下載後通常會在：
- **檔案管理員 → 下載**
- 或通知列點「下載完成」

---

## 第 2 步：允許安裝未知應用程式（紅米）

第一次裝 APK 時，系統會擋下來，這是正常的。

依序做：

1. 打開剛下載的 `ime-switcher.apk`
2. 若出現「為了安全已封鎖」或「禁止安裝」：
   - 按 **設定**
   - 打開「**允許來自此來源**」或「**安裝未知應用程式**」
3. 返回再重新點一次 APK 安裝

如果找不到入口，可手動走：

1. **設定 → 隱私權保護 / 密碼與安全**
2. **特殊應用權限 / 更多權限**
3. **安裝未知應用**
4. 選你用來開檔案的 App（例如「檔案管理員」或 Chrome）→ **允許**

---

## 第 3 步：安裝 App

1. 點 APK → **安裝**
2. 完成後按 **開啟**
3. App 名稱是：**輸入法快捷鈕**

---

## 第 4 步：啟用通知快捷鈕

1. 系統問通知權限 → 按 **允許**
2. 按 **啟用通知快捷鈕**
3. 可再按 **測試：開啟輸入法選單**  
   - 有跳出輸入法清單 = 成功

---

## 第 5 步：之後怎麼切換輸入法

卡在無蝦米時：

1. 螢幕頂端往下拉（通知列）
2. 點「**切換輸入法**」或按鈕「**切換**」
3. 選注音或其他輸入法

---

## 第 6 步：紅米一定要設定（不然通知會消失）

到 **設定 → 應用程式 → 管理應用程式 → 輸入法快捷鈕**：

1. **省電策略** → **無限制**
2. **自啟動** → 開啟
3. **通知管理** → 全部允許

建議設完後重開機一次，確認通知還在。

---

## 常見問題

### 下載後找不到檔案？
打開「檔案管理員」→「下載」。

### 點了 APK 沒反應？
改用系統「檔案管理員」開啟，不要只在瀏覽器預覽。

### 說應用程式不安全、不能安裝？
到「安裝未知應用」把對應來源打開；這不是病毒提示的萬能解除，但自己下載的這個小工具需要這個權限才能裝。

### 通知列沒有快捷鈕？
回 App 再按一次「啟用通知快捷鈕」，並確認通知權限、省電無限制。

### 這個 App 會不會取代無蝦米？
不會。它只是幫你叫出系統輸入法選單。
