# 輸入法通知快捷鈕｜一步一步安裝教學

這份教學假設你**完全不會寫程式**。照著做即可。

你需要：
- 一台電腦（Windows 或 Mac）
- 你的紅米手機
- 一條可以傳資料的 USB 線（充電線有時不行，要用能傳檔的）

整段流程大概是：

1. 電腦安裝 Android Studio  
2. 手機打開「開發人員選項」與「USB 偵錯」  
3. 用 Android Studio 把 App 裝進手機  
4. 在手機裡啟用通知快捷鈕  
5. 設定紅米省電，避免通知被清掉  

---

## 第一步：下載並安裝 Android Studio

1. 用電腦打開瀏覽器，前往：  
   https://developer.android.com/studio
2. 按 **Download Android Studio**
3. 下載完成後安裝：
   - **Windows**：雙擊 `.exe`，一路 Next，勾選安裝 Android SDK
   - **Mac**：打開 `.dmg`，把 Android Studio 拖進 Applications
4. 第一次開啟 Android Studio 時：
   - 選 **Standard**（標準安裝）
   - 等它下載 SDK（可能要一段時間，看網路）
   - 完成後會看到歡迎畫面（Welcome）

---

## 第二步：把專案放到電腦

### 方法 A：你已經有 GitHub 帳號、會下載 ZIP（較簡單）

1. 打開這個網址：  
   https://github.com/trctfa/Payo/tree/cursor/ime-notification-switcher-5dcd
2. 按綠色 **Code** → **Download ZIP**
3. 解壓縮 ZIP
4. 進到資料夾後，確認裡面有一個資料夾叫做 `ime-switcher`

### 方法 B：如果你是用 Cursor / Git 拉下來的專案

專案路徑就是：

`（你的專案根目錄）/ime-switcher`

---

## 第三步：用 Android Studio 開啟專案

1. 打開 Android Studio
2. 在歡迎畫面按 **Open**
3. 選到 **`ime-switcher`** 這個資料夾（注意：是選 `ime-switcher`，不是外層 `Payo`）
4. 按 OK
5. 第一次開啟會右下角出現 Gradle Sync / 下載依賴，**等它跑完**  
   - 若跳出「Trust Project」，按 Trust  
   - 若提示缺 SDK，照提示按安裝即可

成功後，左邊會看到 `app` 資料夾，上方工具列會有綠色三角形 ▶。

---

## 第四步：手機打開開發者模式（紅米 / HyperOS）

在手機上操作：

1. 打開 **設定**
2. 進 **我的裝置**（或「關於手機」）
3. 連續點 **MIUI 版本 / HyperOS 版本 / 作業系統版本** 約 7 次  
   - 會跳出「您已處於開發者模式」
4. 返回 **設定 → 更多設定 → 開發人員選項**
5. 打開：
   - **USB 偵錯**（一定要開）
   - 若有 **USB 安裝**，也打開
6. 用 USB 線把手機連到電腦
7. 手機跳出「要允許 USB 偵錯嗎？」→ 打勾「一律允許」→ 按 **確定 / 允許**

### 連線小檢查

在 Android Studio 上方裝置列表，應該看得到你的紅米型號。  
如果是空白：

- 換一條能傳資料的線
- 手機通知列把 USB 模式改成「檔案傳輸 / MTP」
- 重新插拔線，再按一次允許 USB 偵錯

---

## 第五步：把 App 安裝到手機

1. 在 Android Studio 上方，確認裝置選到你的紅米
2. 按綠色三角形 **Run** ▶  
   或選單 **Run → Run 'app'**
3. 等編譯完成（第一次較久）
4. 手機應會自動安裝並開啟「**輸入法快捷鈕**」

如果失敗常見原因：
- 沒開 USB 偵錯
- 沒允許這台電腦
- 線只能充電
- Android Studio 還在下載東西，再等一下重試

---

## 第六步：在手機啟用通知快捷鈕

App 開啟後：

1. 若系統問「要允許通知嗎？」→ 按 **允許**
2. 按綠色大按鈕：**啟用通知快捷鈕**
3. 畫面上狀態應變成「已啟用」
4. 可先按 **測試：開啟輸入法選單**  
   - 有跳出輸入法清單 = 成功

---

## 第七步：日常怎麼切換輸入法

之後你卡在無蝦米時：

1. 從螢幕頂端往下拉，打開通知列
2. 找到通知：**切換輸入法**
3. 點通知本身，或點按鈕 **切換**
4. 在跳出的清單選 **注音**（或你要的輸入法）

完成。

---

## 第八步：紅米必做設定（很重要）

紅米很愛清背景，不做這步通知常會消失。

### 1）省電改無限制

1. **設定 → 應用程式 → 管理應用程式**
2. 找到 **輸入法快捷鈕**
3. **省電策略 / 省電管理** → 選 **無限制**

### 2）允許自啟動

同一 App 設定頁：

1. 找 **自啟動**
2. 打開允許

### 3）確認通知有開

1. App 設定頁 → **通知管理**
2. 全部允許
3. 頻道「輸入法快捷」不要被關掉或塞進靜音不顯示

做完後建議：
- 重開機一次
- 看通知列是否還有「切換輸入法」
- 若沒有：再開 App 按一次「啟用通知快捷鈕」

## 常見問題

### Q1：通知列找不到快捷鈕？
- 回到 App 確認狀態是「已啟用」
- 檢查通知權限有開
- 省電改無限制
- 通知可能被收到「靜音通知」分頁，展開看一下

### Q2：點了沒有跳出輸入法選單？
- 先在 App 內按「測試：開啟輸入法選單」
- 確認手機已安裝注音 / Gboard 等其他輸入法  
  （設定 → 更多設定 → 語言與輸入法）

### Q3：一定要電腦嗎？
目前這個專案是給 Android Studio 安裝用。  
如果你之後有 `.apk` 檔，也可以直接傳到手機安裝（要允許「安裝未知應用程式」）。  
若你需要，我可以再寫「只裝 APK、不用 Android Studio」的版本教學。

### Q4：會不會改到我的無蝦米？
不會。這個 App 只是幫你叫出系統輸入法選單，不會刪除或修改無蝦米。
