# K 線與股價分析助手（單檔 Landing Page）

使用純前端製作，所有程式已整合在同一個 `index.html`（HTML + CSS + JavaScript）。

## 功能

- 輸入股票代碼、市場、目前股價、時間週期與操作偏好
- 貼上 K 線資料（CSV：`open,high,low,close,volume`）
- 自動產生：
  - 市場狀態（偏多 / 偏空 / 盤整）
  - 價格位置意義（支撐 / 壓力 / 區間）
  - 可能劇本、風險提醒、優化建議
- 內建簡易 K 線視覺化
- 針對手機排版優化（Responsive）
- 內建「下載 index.html」按鈕（手機可用一鍵存檔/分享）
- 支援台股自動抓取日 K：只輸入股票代號即可分析（未貼 CSV 時自動帶入）
- 新增「一鍵抓取並分析」按鈕：輸入股票代號後可直接完成抓資料 + 產生分析

## 如何使用

直接開啟 `index.html` 即可，或使用任何靜態伺服器：

```bash
python -m http.server 8080
```

然後在瀏覽器開啟 `http://localhost:8080`。

## K 線資料格式

每行一筆，欄位順序如下：

```txt
open,high,low,close,volume
```

範例：

```txt
930,938,925,935,21500
935,941,931,940,20100
940,946,936,944,18800
```

建議至少提供 20 根 K，分析會比較穩定。
