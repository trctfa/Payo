# Payo · Kapot 人力盤點

以阿美族**年齡階級（kapot / s'lal）**為核心的部落人力盤點網頁。

依級名登錄族人、統計各階人力、標記動員狀態，方便豐年祭與公共事務動員。單一 HTML，零後端依賴，資料存在瀏覽器 localStorage，可匯出 JSON／CSV 備份。

## 開啟方式

直接用瀏覽器開啟 `index.html`，或放到 GitHub Pages / Netlify / 任何靜態空間。

```bash
# 本機預覽（任選一種）
python3 -m http.server 8080
# 然後開啟 http://localhost:8080
```

## 功能

- **人力階梯看板**：依「由幼至長」顯示各階級人數長條圖
- **族人名冊（三層）**：手風琴先看**階級** → 展開見**華語名／族語名** → 點進去拉出個人資料（電話預設隱藏）
- **階級設定**：自訂部落名稱與級名（襲名／創名皆可自行填入）
- **匯出／匯入**：JSON 完整備份、CSV 名冊；換電腦請先匯出

首次開啟會帶入示範資料，可在「階級與部落設定」改成你們部落的真正級名，或按「載入示範資料」重置。

## 關於年齡階級（簡述）

阿美族男子多自青少年起進入會所體系，以年齡編成一級一級的組織，共同承擔防衛、祭儀、公共勞動。同一級互稱 **kapot**，視同手足。

級名制度各地不同：

- **襲名制**（常見於中、北部）：級名在部落內循環使用
- **創名制**（常見於南部）：依該屆大事命名，級名常以 La／Ra 開頭

本工具不綁定特定部落的級名，請依各部落習慣自行設定。

## 隱私

所有資料只存在使用者自己的瀏覽器，不會上傳到伺服器。公開場合操作前請留意螢幕內容。
